# Changelog

## v1.0.1

### Release
- Added Infinite Charge support for Station Batteries.
- Added Infinite Charge support for Battery Cells.
- Uses each battery's own maximum charge capacity.
- Confirmed working with standard, large, and Nuclear Battery Cells.
- Added ON/OFF toggle support.
- Added Stationeers-native Controls menu integration.
- Default toggle key is F7.
- Keybinding can be changed through Stationeers Controls.
- Confirmed rebinding works with F6.
- Improved input polling so quick key presses are detected reliably.
- Battery refresh interval reduced to 250 ms to prevent visible charge flicker.
- Removed experimental Harmony patches.
- Removed obsolete runtime GameObject/coroutine experiments.
- Removed unused BepInEx configuration entries.
- Removed 0Harmony dependency.
- Removed UnityEngine.InputLegacyModule dependency.
- Cleaned diagnostic logging and source structure.
- Release build tested successfully in-game.
