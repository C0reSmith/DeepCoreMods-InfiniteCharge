# Installation – DeepCore Mods Infinite Charge

## Requirements

- Stationeers
- BepInEx 5
- Windows

## Install

1. Close Stationeers.
2. Open the Stationeers installation folder.
3. Open:

   `BepInEx\plugins\`

4. Create a folder named:

   `DeepCoreMods.InfiniteCharge`

5. Copy:

   `DeepCoreMods.InfiniteCharge.dll`

   into that folder.

The final path should look like:

`Stationeers\BepInEx\plugins\DeepCoreMods.InfiniteCharge\DeepCoreMods.InfiniteCharge.dll`

6. Start Stationeers.
7. Open **Settings → Controls**.
8. Locate **DeepCore Mods - Infinite Charge**.
9. The default key is **F7**.
10. Change the key in Stationeers Controls if desired.

## Verify

After loading the game:

1. Confirm batteries remain full.
2. Press the configured toggle key.
3. Batteries should begin discharging normally.
4. Press the key again.
5. Supported batteries should return to full charge.

## Uninstall

Delete:

`DeepCoreMods.InfiniteCharge.dll`

from the mod folder.

No separate BepInEx `.cfg` file is required.
