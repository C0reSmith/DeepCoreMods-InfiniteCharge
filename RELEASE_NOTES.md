# DeepCore Mods – Infinite Charge v1.0.1

Infinite Charge keeps Stationeers batteries fully charged while enabled and lets you toggle the feature directly from a configurable Stationeers Controls key.

### Tested
- Station Battery
- Standard Battery Cell
- Large Battery Cell
- Nuclear Battery

### Controls
Default: **F7**

The key can be changed from:

**Settings → Controls → DeepCore Mods - Infinite Charge**

### Technical
- Uses the battery object's own maximum charge value.
- 250 ms charge refresh.
- 50 ms toggle-key polling.
- No Harmony dependency.
- No separate BepInEx config file required.
- Windows build.
